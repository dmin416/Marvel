# D Story: Marvel-Inspired World

Planning files for D's interactive story, set in an original world built from Marvel and other inspirations. The only story canon is `D-Story-So-Far.txt`. Everything else is planning ideas.

The same files live in the claude.ai Project "Marvel". The project uses different file names, listed below.
